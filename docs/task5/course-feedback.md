# Task5 课程反馈

第 5 章用委派描述、独立对话和共享 Backend 解释 Context Quarantine，并说明声明式子 Agent 的字段继承规则。本次实验从这三处入手，能够对应到实际运行记录。 [第 5 章课程正文](https://datawhalechina.github.io/deepagents-in-action/chapters/ch05-subagents/)

1. **给上下文隔离配一组可观察的标记。** 在主消息、各角色提示词和研究工具结果里放入无敏感信息的标记，再检查哪些进入子 Agent、哪些进入主对话。本次据此确认，子 Agent 从委派描述开始工作，原始研究工具标记没有进入主消息。

2. **配一个固定路径的文件交接示例。** 建议明确研究员的写入路径和写手的读取路径，再展示 Backend 中真实存在的文件。模型自行增加 `/app` 前缀就可能让交接失败。文件可共享与模型是否使用同一路径，需要分别观察。

3. **并排展示消息返回和状态更新。** 本次两个 `task` 的消息更新都只有一条最终回答，状态更新同时包含 `files`，没有子 Agent 的 Todo 与 Skills 元数据。把这两部分一起展示，能更准确理解主 Agent 收到的内容。

4. **在概念实验中固定实现版本。** 当前官方概览出现了较新版本的配置，直接用于本机 `0.7.8` 实验容易引入不适用的参数。建议注明示例版本，并将关键机制指向对应源码。检查产物时也应复核摘要中的结论，避免一个角色的误读被后续角色沿用。 [本次可运行示例](../../examples/task5/subagent_pipeline.py)
